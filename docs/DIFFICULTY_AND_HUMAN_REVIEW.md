# Difficulty and human review

Difficulty labels are provisional predictions. Certification retains optimal moves, reachable and doomed states, meaningful decisions, earliest meaningful branch, forced-move ratio, exact minimum Bloom-assisted stops, and canonical creator-to-use distance. Numeric gates match profile version 1; qualitative pacing, clarity, relief, and fun remain review questions.

The automated report is [certification-summary.json](../reports/content/certification-summary.json). The 100-row [human-review-worksheet.csv](../reports/content/human-review-worksheet.csv) records reviewer, attempts, time, Undo/Restart/hint usage, perceived difficulty, duplicate concern, decision, and notes.

No human playtest data has been entered. The campaign is suitable for internal/closed testing but is not human-validated or production-release validated. Recalibration should preserve raw metrics and use representative players rather than changing labels from solver depth alone.
